# M01 — 專注閱讀模式（2026-10-15）

## 實際需求

現有首頁同時呈現大標題、收音設定、工程資訊以及字幕。對於只需要看見對話文字的長者，這些元素會壓縮手機上的字幕閱讀高度。既有字體大小、近期回顧、字幕生命週期均已開發，本次不修改其內容及 STT 性能。

## 互動設計

- 在「即時字幕」標題旁加入清楚的「專注閱讀」開關，啟用後文字改為「返回一般畫面」，並使用 `aria-pressed` 表示狀態。
- 專注模式隱藏首頁說明、進階／研究資訊、版本註記及收音設定區，騰出更多字幕空間。保留正在聆聽狀態、**開始／停止**、畫面常亮提示、**剛剛說什麼**和字級選項。
- 保留回顧面板，在專注模式也可使用近期與完整字幕複製；返回一般畫面便可調整 Auto／遠距離／吵雜。
- 手機直式使用約 53dvh、矮橫式約 43dvh 作為字幕區高度目標，仍允許必要的頁面或字幕內捲動，不承諾所有設備完全免捲動。
- 模式是每個頁面的展示偏好，重新開啟預設一般畫面；不寫入本機儲存、不修改前處理、音訊來源或辨識 session。

## 驗證

- Node 測試涵蓋開關與 `aria-pressed`、反覆切換、基本控制存在、只隱藏非核心介面、無任何音訊或持久化 API。
- GitHub Actions Playwright Chromium E2E 同時在手機直／橫尺寸檢查：字幕高度確實增加、主要按鈕仍可見、文字與字級選擇不重置、橫向無不必要溢出、不需啟動麥克風。
- 這是 UI 層驗收，**不是 Android/iPhone 實機視覺驗收**，也不代表 Gemini 辨識、藍牙延遲、SPL/MPO 或安全助聽路由改善。
- 產品試用時可只請使用者觀察一次專注閱讀的字體、停止按鈕是否清楚，不重做 SW1–SW4 測試。
