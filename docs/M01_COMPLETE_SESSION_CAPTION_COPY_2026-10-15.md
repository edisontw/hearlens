# M01 — 本次完整字幕手動複製（2026-10-15）

## 使用情境與選擇

使用者可在「剛剛說什麼？」查看和複製最近 30 秒的字幕。較長門診、家庭或其他對話有時需要回看更早的已確認文字。本功能在原有回顧面板提供第二個明確操作：「複製本次完整字幕」，而非把歷史字幕重新塞進日常即時顯示框。

## 實作與資料邊界

- 僅使用既有 `sessionFinals` 記憶體集合的 `text`，按收到的順序以換行組成文字。超過 30 秒的 final 仍包含，partial/interim、原始音訊、rawText、STT 工程 log 與其他欄位都不輸出。
- 沒有任何 finalized 字幕時禁用按鈕；使用者每次主動開始新 session 時清除舊 finals，並重設按鈕；停止後仍可複製這次已有的 finals，直到重新開始或關閉頁面。
- 操作會要求瀏覽器複製至系統剪貼簿。剪貼簿不是 HearLens 儲存空間，可能被其他應用讀取；已顯示隱私提示。瀏覽器拒絕權限時顯示失敗，不聲稱已完成複製。
- 原有 30 秒即時字幕、近況回顧、字幕字級、語音辨識、麥克風生命週期、Gemini、聽力圖及所有音訊輸出安全條件皆不更動。
- 此選項不做自動儲存、檔案下載、雲端同步、摘要、身分辨識或錄音。原有技術性 session report 仍沿用既有機制。

## 驗收範圍

- 單元測試：finals 文字順序、跨過 30 秒仍保留、空白忽略、不變更原始資料。
- UI 契約測試：無 finals 時禁用、綁定手動 click、連結正確記憶體來源、每次開始新 session 清空。
- GitHub CI 驗證後再合併。
- 本功能不代表實機 Android/iOS 剪貼簿驗收或宣稱字幕辨識正確性；無任何助聽擴音許可。
